# Go Card Manager

Go Card Manager is a personal web application designed to help collectors organize and manage their photocard collections.

The application allows users to create boards, manage card quantities, track collections, and import or export data for backup purposes.

## Features

- Create and manage collection boards
- Add and edit cards
- Track card quantities
- Organize cards in customizable grids
- Manage participants
- Import and export data
- Full backup and restore support
- Local storage persistence (no server required)
- Responsive and easy-to-use interface

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## Project Structure

```
index.html   - Main page and UI structure
style.css    - Application styling
script.js    - Application logic
images/      - Card images
```

## Running the Project

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

Alternatively, you can run the project using VS Code Live Server.

## Usage

### Home Screen

- Create new boards
- Select existing boards
- Manage participants

### Board Screen

- View cards in a grid layout
- Update card quantities
- Open card details
- Add or edit cards

### Data Management

- Export boards
- Import boards
- Create a full backup
- Restore from backup

## Data Storage

All data is stored locally in the browser using LocalStorage.

No external database or backend server is required.
